Задание 4 - Конвейер с деталями 

**Сущности системы:** \
*Конвейер (Conveyor)* \
Свойства: \
Название — идентификатор конвейера (Line-1, Line-2, etc.) \
Материалы — процент оставшихся материалов (0–100%) \
Детали — количество произведённых деталей \
Статус — текущее состояние (запущен, остановлен, сломан) \
IsBroken — признак поломки конвейера

События: \
MaterialLow — заканчиваются материалы (требуется загрузка) \
Broken — конвейер сломался (требуется ремонт) \
PartProduced — произведена новая деталь \
StatusChanged — изменение статуса конвейера

*Погрузчик (Loader)* \
Автоматически загружает новую партию материалов при событии MaterialLow.

*Механик (IMechanic)*\
Автоматически ремонтирует конвейер при событии Broken (срабатывает с вероятностью поломки ~2%).

**Описание приложения** \
Приложение демонстрирует работу производственного конвейера и позволяет:
-добавлять несколько конвейеров на форму (до 10);
-наблюдать за расходом материалов в реальном времени;
-видеть процесс производства деталей;
-отслеживать статус каждого конвейера;
-автоматически пополнять материалы через Погрузчика;
-автоматически ремонтировать конвейеры через Механика;
-управлять всеми конвейерами одновременно (запуск/остановка/очистка).

**Что используется в проекте:** \
C# \
.NET 8 \
Avalonia UI \
MVVM паттерн 

**Сценарий работы** 

*Запуск конвейера* \
-Нажмите «Добавить» — создаётся конвейер со 100% материалов \
-Конвейер автоматически начинает производство 

*Производство деталей* \
-Материалы постепенно расходуются (100% → 0%) \
-Счётчик деталей увеличивается 

*Загрузка материалов* \
-При 0% материалов Погрузчик автоматически загружает +50 единиц \
-Прогресс-бар восстанавливается

*Поломка и ремонт* \
-С вероятностью ~2% конвейер может сломаться \
-Появляется индикатор ⚠️ СЛОМАН \
-Механик автоматически ремонтирует (~3 секунды) \
-Производство возобновляется

*Управление несколькими конвейерами* \
-Можно добавить до 10 конвейеров одновременно \
-Кнопки «Запустить»/«Остановить» управляют всеми сразу
-Каждый конвейер работает независимо
